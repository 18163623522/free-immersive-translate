# 沉浸式免费翻译 (free-immersive-translate)

类似「沉浸式翻译」的浏览器双语对照翻译插件，AI 全部使用**免费模型**。纯原生 Chrome/Edge MV3，零构建、加载即用。内置 PDF.js 双语 PDF 查看器与**图片/漫画翻译**（视觉模型免费档）。

## 功能

- **双语对照**：译文显示在原文段落下方，字号 0.95em
- **8 种译文样式**（设置页画廊可视化选择、即时预览）：
  - 简约彩字（默认，颜色可自定义）
  - 悬停显示（译文模糊，鼠标掠过才清晰）
  - 虚线下划线 / 浅色底纹 / 引用竖线 / 卡片边框 / 斜体淡彩
  - 荧光笔（黄色标记划过，文字色跟随原文）
  - 改样式/颜色对**已翻译的页面即时生效**，无需重新翻译
- **段落级智能收集**：只翻正文块（p/h1-h6/li/blockquote/td…），自动跳过代码块、脚本、隐藏元素、已是目标语言的段落
- **两种触发方式**：页面右下角悬浮球 / 快捷键 `Alt+A` / 工具栏弹窗按钮
- **批量翻译**：段落按条数+字符量切批，JSON 编号对齐回填，页面侧并发 2、后台并发 3，失败自动重试 1 次，失败段落点击即可重试
- **再次点击还原**原文（翻译进行中点击 = 打断），互不污染 DOM
- **多 iframe 支持**：正文在 iframe 里也能翻（悬浮球只在顶层显示）
- **PDF 翻译（v0.7 三种布局，工具条随时切换）**：在 PDF 页面点悬浮球（或 Alt+A）进入双语查看器——
  - **覆盖**：译文行覆盖原文，悬停透视，适合保持原版式
  - **网页**：像网页翻译一样——PDF 文本抽取合并成段落，原文 + 译文对照流式阅读，可复制
  - **双页**：左原文页、右译文列，双页对比阅读
  - 内置 CJK cmaps；缩放后重译走缓存；行合并为段落按行距自动判断
- **YouTube / B 站双语字幕**：自动拦截字幕请求并翻译，每条字幕渲染为「原文 / 译文」两行；
  悬浮球菜单「视频字幕」可开关（默认开）
- **翻译结果持久缓存**：文本与图片翻译结果存本地（7 天有效，跨页面/会话），
  重开页面零请求秒出；**双击译文可手动修正**，修正写入缓存
- **导出双语 HTML**：翻译完成后悬浮球菜单一键导出，译文 canvas 固化为图片，离线可看
- **翻译面板（Alt+S）**：右侧滑入的翻译面板，输入即译（Ctrl+Enter），带本次浏览历史和**译文朗读**（本地 TTS）
- **自动翻译**（设置页开启）：打开语言不符的页面自动开始翻译，支持站点黑名单（每行一个域名，支持 `*.xxx` 通配）
- **增量翻译**：翻译后页面新加载的内容（无限滚动）自动补翻，还原即停
- **右键菜单**：翻译/还原本页、翻译选中文字、翻译此图片
- **自定义翻译指令**（设置页）：注入术语表或风格要求，优先级高于默认风格
- **图片/漫画翻译**（v0.4，对标沉浸式翻译的漫画功能，全免费）：
  - 悬停大图片出现「译」按钮，单图翻译；已翻译显示「↺」可还原
  - 弹窗「翻译本页图片（漫画模式）」或悬浮球菜单批量翻译页面上所有大图（并发 2）
  - 视觉模型（默认智谱 `glm-4.6v-flash` 免费，与文本 Key 通用）一次返回
    所有文字框坐标+译文 → canvas 抹除（取文字框边缘中位色，不生硬白块）+
    自适应字号/换行重绘；悬停译文层半透明可透视原图，点击还原
- **MIUIX / HyperOS 设计语言**：设置页三段式（翻译服务/译文样式/图片翻译）、
  弹窗与页面交互组件均按 MIUI 规范（MIUI 蓝 #3482FF、16dp 圆角卡片、
  开关/单选列表/按压反馈），支持系统暗色模式
- **悬停段落翻译**（悬浮球菜单开启）：鼠标在某段落停留 600ms 自动翻译该段，指哪翻哪
- **划词翻译**：选中文字后浮出「译」按钮，点击弹出译文气泡（点击外部关闭）
- **输入框翻译（Alt+I）**：聚焦输入框按 Alt+I 把内容翻成对方语言（中文→英文），再按一次还原原文
- **仅显示译文**（悬浮球菜单开启）：隐藏原文只看译文，可随时切回双语
- **悬浮球全功能**：点击翻译/还原；右键或长按弹出菜单（翻译图片/重新翻译/悬停翻译/仅译文/8 样式/设置）；按住拖到任意边缘，位置自动记忆

## 安装

1. Chrome 打开 `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `free-immersive-translate/`
4. 点扩展图标 → 设置 → 填入 API Key → 「测试连接」

## 免费 AI 配置（三选一，默认已选智谱）

| 服务商 | 免费模型 | Key 获取 | 备注 |
|---|---|---|---|
| **智谱 BigModel**（默认） | `glm-4.5-flash` | [open.bigmodel.cn](https://open.bigmodel.cn/userinfo/apikey) 注册即得 | 完全免费、国内直连、128K 上下文 |
| 硅基流动 | `Qwen/Qwen3-8B` 等带「免费」标签款 | [cloud.siliconflow.cn](https://cloud.siliconflow.cn/account/ak) | 0 元小模型，有 RPM 限速 |
| Groq | `llama-3.3-70b-versatile` | [console.groq.com](https://console.groq.com/keys) | 免费档，国内需代理 |

**本地模型（也免费）**：服务商选「自定义」，地址填 `http://localhost:11434/v1/chat/completions`（Ollama），Key 任意填，模型如 `qwen2.5:7b`。OpenRouter 等 OpenAI 兼容平台同理（免费模型名以 `:free` 结尾）。

## 目录结构

```
manifest.json      # MV3 清单（权限：storage/tabs，<all_urls> 注入）
background.js      # Service Worker：LLM 调用、限速、JSON 解析、快捷键分发
content.js         # 内容脚本：段落收集、语言判定、批量翻译、悬浮球、PDF 检测跳转（含 mock 测试桥）
content.css        # 双语样式 + 悬浮球样式
popup.html/js      # 工具栏弹窗
options.html/js    # 设置页（服务商/Key/模型/目标语言/译文样式画廊/颜色）
pdf/               # 双语 PDF 查看器（pdf.js 4.10 + viewer 三件套 + cmaps/standard_fonts）
icons/             # 图标（tools/gen_icons.py 生成）
test/harness.html  # 网页翻译逻辑实测页（mock 翻译桥，无需装扩展即可验证 content.js）
test/sample.pdf    # 手写测试 PDF（gen_sample_pdf.py 生成，验证 viewer）
test/serve.py      # 本地测试服务器（修正 .js/.mjs MIME，Windows 注册表坑）
```

## 测试

```bash
cd free-immersive-translate
python test/serve.py 8124
# 网页翻译：http://127.0.0.1:8124/test/harness.html（点悬浮球；左上角切换 8 种样式；底部图片区 hover 出「译」按钮）
# PDF 翻译：http://127.0.0.1:8124/pdf/viewer.html?mock=1&file=../test/sample.pdf
# options.html / popup.html 可直接打开预览 MIUIX 界面
```

已验证：11/11 英文段落翻译与跳过逻辑；8 种样式断言；打断还原；设置页三 tab/开关/单选交互。PDF：渲染/行聚类/覆盖译文/对照/缩放/缓存。图片翻译：hover 按钮出现与隐藏（含小图忽略）、单图翻译 canvas 位图与像素级断言（文字绘制+背景抹除）、margin 迁移布局无损、点击还原、二次 hover 状态切换（译/↺）。

注：真实使用——网页翻译点悬浮球或 Alt+A；图片翻译悬停图片点「译」；漫画/图库页点扩展弹窗「翻译本页图片」；PDF 页点悬浮球进入双语查看器（`file://` 本地 PDF 需在扩展管理页开启「允许访问文件网址」）。

## 隐私

API Key 仅存于本地 `chrome.storage.sync`；翻译请求由浏览器直连所选服务商，不经过任何中间服务器。

## 已知限制（v0.3）

- 行内加粗/链接等富文本样式在网页译文中不保留（纯文本回填，安全无 XSS）
- SPA 页面路由切换后新增内容不会自动翻译，再点一次悬浮球即增量翻译
- PDF 译文按行覆盖在原文上（固定版面没有插入空间），悬停可透视原文；扫描版 PDF（无文本层）无法翻译
- `file://` 本地 PDF 需在 `chrome://extensions` → 本插件 → 详情 → 开启「允许访问文件网址」
